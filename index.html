À propos du projet

Ton jeu, adapté pour le web.

Ton code d’origine utilise Python et Pygame. Un navigateur ne peut pas exécuter directement ce fichier Python : le jeu intégré à cette page reprend donc sa logique en JavaScript et Canvas. Pour lancer la version Python originale, utilise toujours la commande python geometry_dash.py. Projet fan non officiel.
